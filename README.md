# 탠트럼 두더지

《미스 탠트럼, 진짜 영애가 되다!》의 주인공 미스 탠트럼을 크로케 망치로 혼쭐내는 두더지 잡기 게임.

- 50타마다 속도 UP, 100타마다 등급 UP, 200타마다 심장 칸 +2
- 1,001타를 넘기면 '탠트럼 전담 일진'
- 음악과 "아야!" 목소리는 모두 Web Audio로 합성 (오디오 파일 없음)
- 공유 랭킹 TOP 50

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 전체 (HTML·CSS·JS 한 파일) |
| `api/scores.js` | 랭킹 API (Vercel 서버리스 함수) |

## 랭킹 저장소 연결 (Vercel)

1. Vercel 프로젝트 → **Storage** → **Upstash for Redis** (Marketplace) → 데이터베이스를 만들고 이 프로젝트에 연결
2. 연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 환경 변수가 자동으로 들어간다 (`UPSTASH_REDIS_REST_URL`/`_TOKEN` 이름도 인식)
3. **Redeploy** 한 번

저장소가 연결되기 전에는 게임 화면에 "랭킹 서버를 준비 중이에요"가 뜨고, 게임은 그대로 할 수 있다.

## 랭킹 규칙

- 플레이어마다 브라우저에서 만든 id·비밀값을 쓴다. 같은 브라우저만 자기 기록을 바꿀 수 있다.
- 최고 기록만 남는다. 플레이 시간 대비 너무 많은 타수, 분당 20회 넘는 제출은 거절한다.
- 로그인이 없으므로 조작을 완전히 막지는 못한다. 이상한 기록은 Upstash 콘솔에서 `tw:scores`(정렬 집합)의 해당 id를 지우면 된다.
